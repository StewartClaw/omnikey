# OMNIKEY 5427 G2 — IT&C 567 End of Semester Project

Security research project on a BYU-issued HID OMNIKEY 5427 G2 reader (part R54270111-UNI-ELITE).

- `omnikey-5427g2-backup/` — baseline backup of the reader's original state (read before any changes).

## Ground rules
- No firmware updates, no factory reset (the BYU iCLASS Elite keys can't be restored).
- Back up the current value before every settings change, and record each change in `omnikey-5427g2-backup/README.md`.

======================================================================
1. WHAT IT IS
======================================================================
A desktop USB + Bluetooth (BLE) RFID / smart card reader made by HID Global.
"G2" = second generation of the 5427 (the USB name is still "5427 CK").
It reads both 125 kHz proximity cards and 13.56 MHz smart cards.
This unit is BYU-issued and loaded with HID iCLASS Elite keys (see section 6).

It has two operating modes:
  - Keyboard wedge (default as received): it acts like a USB keyboard and
    types the card number into whatever window has focus.
  - CCID (PC/SC): it acts like a standard smart card reader, so software can
    send commands (APDUs) to cards and to the reader itself.

6. SECURITY-RELEVANT FACTS
======================================================================
- "ELITE" = HID iCLASS Elite: a custom key set assigned to one customer
  (likely BYU), loaded into the SAM by HID. The keys can't be read out. The
  reader uses them internally to unlock and decode iCLASS/Seos credentials.
- [I] A factory reset (Workbench MIB "Restore" command) might wipe custom
  settings or keys. Only HID can reload Elite keys. -> RULE: NO FACTORY RESET.
- Firmware is HID-signed. It can't be dumped or rolled back. -> RULE: NO FW UPDATE.
- Settings live in flash with an "active" copy and a "backup" copy.
  Workbench's code documents the MIB control commands Apply / Reset / Store /
  Restore / Reboot. Source: OMNIKEY 5x27 Software Developer Guide, Appendix B.2.3.3.
- Keyboard wedge mode sends the card number as plain keystrokes. Any app with
  focus, including a keylogger, receives it. KW Encryption is OFF. [V]
- The web console is plain HTTP with NO access password. Anything that can
  reach 192.168.63.99 over the EEM link can read and change the config and
  reach the firmware/config upload. [V]
- "Config cards" polling is enabled: a configuration card could reprogram
  the reader. [V]
- TFTP is enabled: an extra firmware/config transfer channel is open. [V]
- Prox (125 kHz, no crypto) is enabled alongside iCLASS/Seos. [V]
- The exported config file is encrypted, so it can be restored but not
  read or edited directly. [V]
These findings are recorded only. Nothing was changed on the reader.

11. HOW TO PROTECT IT (hardening checklist for the report's mitigations)
======================================================================
Credentials
  - Prefer Seos or iCLASS SE/Elite (SIO-based, mutual authentication) over
    125 kHz Prox or MIFARE Classic, which have weak or no cryptography.
  - Disable unused card technologies in the reader config so it only
    accepts what the organization actually issues.
  - Use the card's protected PACS/SIO data, not the CSN (card serial
    number), as the identifier. A CSN alone is not a secret.

Management interfaces
  - Set an Access Password on the web console (ours has none).
  - Disable the EEM web interface when it isn't needed
    (IsEemInterfaceEnabled = false / EEM Enable OFF).
  - Disable TFTP if it isn't used (ours is ON).
  - Turn off SNMP or restrict it; change default community strings.
  - Disable "Config cards" polling if not needed (ours is ON). Otherwise,
    control who holds configuration cards. Treat them like admin keys.
  - Disable Prox (125 kHz) if the organization doesn't issue Prox cards.
  - Turn on Keyboard Wedge Encryption if wedge mode is used.
  - Keep firmware current using ONLY HID-signed updates from hidglobal.com.

Host PC
  - Keyboard wedge mode: input goes to whatever window has focus. Use CCID
    mode where possible, so applications ask for card data explicitly.
  - Workbench's local API (localhost:5000) has no authentication. Install
    Workbench only on admin machines and close it when not in use.
  - Least privilege: standard users shouldn't be able to install drivers or
    run config tools.
  - Get drivers only from hidglobal.com and verify the "HID Global" code signature.

Physical / lifecycle
  - Asset-tag readers and track serial numbers (Elite keys are site-specific).
  - Lost or retired Elite readers: notify HID / security team; don't resell.
  - Keep a configuration baseline (like omnikey-5427g2-backup/) and review changes.
